# Страховой ассистент для внутреннего использования в страховой компании

---

## О проекте

Внутренний ИИ-ассистент для сотрудников страховой компании, который отвечает на вопросы по страховому законодательству Казахстана, используя только загруженные официальные документы. Система построена по архитектуре **Retrieval-Augmented Generation (RAG)**, что гарантирует ответы основанные на актуальных правовых нормах и исключает галлюцинации.

> **Ключевая особенность:** в отличие от типовых чат-ботов, ассистент **ссылается на конкретные статьи и пункты законов** (благодаря умному парсингу структуры документов) и сообщает, если ответа нет в базе знаний.

---

## Выполненные требования 

| № | Требование | Реализация |
|---|------------|-------------|
| 1 | Использовать предоставленные Word-файлы законов | Парсинг `.docx` через `python-docx` с сохранением статей, пунктов и таблиц |
| 2 | Эффективный поиск релевантных норм | Векторная БД ChromaDB и эмбеддинги `intfloat/multilingual-e5-large` |
| 3 | Точные и корректные консультации | Строгий системный промпт, простая groundedness-проверка, ответ только на основе контекста, запрет галлюцинаций |
| 4 | Обновление базы знаний и adilet.zan.kz | Через UI загрузка новых `.docx`б есть демо-скрипт парсинга с adilet.zan.kz (`adilet_demo.py`) |
| 5 | Удобный интерфейс | Чат на Streamlit, история диалога, раскрывающиеся блоки источников с указанием статьи/пункта |
| Доп. | Механизм обучения на текстах | RAG и эмбеддинги дают модели понимать отраслевую терминологию, сбор простой обратной связи для дальнейшего улучшения |

## Архитектура

```
.docx файлы с законами
↓
[ingest.py] парсинг, выделение статей/пунктов/таблиц и семантический чанкинг
↓
эмбеддинги 
↓
ChromaDB 
↓
[app.py] Streamlit UI
↓
вопрос пользователя > retriever.py и top_k релевантных чанков
↓
контекст и метаданные (статья, пункт), Groq API (Llama 3.1 8B)
↓
[app.py] отображение ответа, источников и кнопки обратной связи
```

## Быстрый старт

### 1. Клонирование и окружение
```bash
git clone https://github.com/yeldanabb/nomad-assistant.git
cd nomad-assistant
python -m venv venv
source venv/bin/activate       # Linux/Mac
venv\Scripts\activate          # Windows
```
### 2. Установка зависимостей
```bash
pip install -r requirements.txt
```
### 3. Индексация законов
Поместите .docx файлы законов в папку data/laws/ и запустите:
```bash
python src/ingest.py
```
После успешной индексации в папке vectorstore/ появится база ChromaDB.

### 4. Настройка API ключа
Зарегистрируйтесь на console.groq.com, получите API-ключ и вставьте его в src/assistant.py (или используйте переменную окружения GROQ_API_KEY).

### 5. Запуск интерфейса
```bash
streamlit run app.py
```

## Тестирование и примеры
Пример корректного ответа (вопрос из базы)
Вопрос:
«Что такое страховой случай по Гражданскому кодексу? Перечислите признаки.»

Ответ ассистента:
Согласно статье 817, пункт 3 Гражданского кодекса Республики Казахстан, страховой случай определяется следующими признаками:

Вероятность и случайность наступления события;
Непредсказуемость относительно конкретного времени или места наступления события, а также размера убытков в результате наступления события;
Отсутствие опасности того, что событие неизбежно и объективно должно произойти в пределах действия договора, о чем стороны или, по крайней мере, страхователь заведомо знали или заранее были осведомлены;
Наступление события имеет отрицательные, невыгодные экономические последствия для имущественного интереса страхователя (застрахованного, выгодоприобретателя).
Примечание: Эти признаки не применяются к событиям, которые могут быть предусмотрены по договору накопительного страхования.

Пример вопроса вне базы знаний
Вопрос: «Какая ставка НДС в Казахстане?»
Ответ:
Согласно предоставленным фрагментам законодательства, в них нет информации о ставке НДС в Казахстане.
Внимание: ответ не содержит ссылок на конкретные статьи. Проверьте информацию по первоисточникам.


## Сбор обратной связи 
В интерфейсе под каждым ответом есть кнопки 👍 / 👎. При клике в файл feedback.json сохраняется: вопрос, ответ, использованные источники, оценка. Это позволяет отслеживать качество ответов, выявлять проблемные запросы и в будущем дообучать ретривер или корректировать чанкинг.
